The READ-ONLY analytical surface of workforce-management's "Labor Utilization & Staffing" data product (ADR 0010), served by the separate `cmd/workforce-reports` binary over a read-only Postgres pool against the analytical database. It is NOT the OLTP `cmd/workforce` API documented in apis/openapi.yaml: a different binary, port and database (ADR 0037).

The report is a projection over this service's own domain events, delivered as CloudEvents 1.0 on the `warehouse.workforce.analytics` topic and applied by `cmd/workforce-projector`, the single writer. It is EVENTUALLY CONSISTENT, to a freshness target of p95 event-to-report lag under 30 seconds: read GET /reports/labor/freshness to see how far the read model trails the event stream.

Rows are keyed by process path (`pathId`) and UTC hour bucket. Associate-scoped events carry no path (this context stops at the path boundary, ADR 0002), so their counters land on the row whose `pathId` is the empty string. No route requires authentication (ADR 0018). Errors use RFC 7807 problem details (`application/problem+json`, ADR 0005).
